# MacDoats logo brief

- **Name:** MacDoats (exact casing). macOS menu-bar companion for Dota 2: cursor lock, shortcut blocking, modifier remapping.
- **Audience:** Mac Dota 2 players, many old enough to remember DotA 1 / Warcraft III.
- **Adjectives:** nostalgic, native Mac.
- **Keep (equity):** Necronomicon book (tilted, bookmark ribbon), ⌘ Command symbol, Dota red #B8312A / gold #E0C387.
- **Primary use:** macOS app icon (squircle). Menu-bar glyph can be a simplified cut later.
- **Avoid:** Valve's Dota shield; Storybook's upright bookmarked book; gaming clichés (swords, shields, skulls, flames, controllers).
- **Decision-maker:** the user.

## Word map
- Name → Mac, Dota, oats; M, D.
- Offering → lock, block, bind, keys, control.
- Nostalgic → DotA 1 item icons, beveled square slots, tomes, runes, Necronomicon.
- Native Mac → ⌘, keycap, squircle, menu bar.
- Intersections: ⌘ is itself an old Nordic sign (the looped square "sight" marker), so ⌘ ↔ rune; keycap ↔ WC3 item slot; Dagaz ᛞ (D) contains Mannaz ᛗ (M) → MD bind-rune.

## Concept longlist
1. Tome of Command: Necronomicon with ⌘ as the cover sigil. *(pictorial)*
2. MD bind-rune: ⌘ whose square becomes Dagaz ᛞ, which holds Mannaz ᛗ. *(letterform/abstract)*
3. Item-slot key: ⌘ on a Mac keycap framed like a WC3 inventory slot. *(emblem)*
4. Open tome whose pages form an M.
5. Bookmark ribbon tied in a ⌘ loop.
6. Two leaning books forming an M.
7. ⌘ whose four loops are four tiny tomes.
8. Oat grain sigil (pun) — dropped: not in the adjectives.

Picked 1, 2, 3: three different mark types, all built on the equity.
